# Product & UI Documentation

Tài liệu UI của Peopleflow HR Leave Management được đối chiếu với source code trên branch master ngày 02/11/2026.

## Tài liệu

- [Design System](DESIGN_SYSTEM.md): visual identity, color tokens, typography, layout, component standards, responsive và accessibility.
- [Wireframes](WIREFRAMES.md): điều hướng theo role, bố cục từng màn hình, luồng nghỉ phép, API traceability và các UX gap.

## Quy ước

Các tài liệu phân biệt:
- Hành vi đã thấy trong source code hiện tại.
- API đã tồn tại nhưng UI chưa cung cấp.
- Đề xuất cải tiến chưa triển khai.

Khi cập nhật frontend hoặc API, cần rà soát lại tài liệu tương ứng để giữ đồng bộ với implementation.
